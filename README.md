# Full-Stack E-Commerce Platform

A full-stack e-commerce application developed using React and Spring Boot, providing a complete shopping experience with product browsing, cart management, checkout, order tracking, and integrated payment gateway functionality.

## Key Features

- **Product Catalog:** Browse products, view product details, and explore categories.
- **Shopping Cart:** Add and manage cart items and calculate order totals.
- **Checkout and Orders:** Support the checkout workflow and order tracking.
- **Payment Integration:** Integrate the payment gateway into the checkout process using a hosted payment interface.
- **Payment Webhooks:** Process payment notifications and synchronize payment status with orders.
- **Authentication and Authorization:** Secure API endpoints using JWT-based authentication.

## Technology Stack

- **Frontend:** React, Redux, Material UI, Tailwind CSS, Axios
- **Backend:** Java, Spring Boot, Spring Security
- **Database:** PostgreSQL
- **Authentication:** JWT
- **Payment Integration:** Payment Gateway
- **API Communication:** REST APIs

## Project Structure

- `Frontend/` — Customer-facing e-commerce application.
- `Backend/` — Spring Boot backend and REST APIs.

## Project Status

Developed as a practical full-stack project demonstrating frontend and backend development, REST API integration, database persistence, authentication, and payment processing workflows.
